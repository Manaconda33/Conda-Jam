# Echo Catwalk mask v6

Status: **rejected; runtime gate remains closed for this iteration**.

V6 classified saturated teal/cyan primary garment pixels by hue and a frame-relative torso/shorts region; secondary shorts pixels used a separate hue band. It kept alpha, outline pixels, and source dimensions. The matrix script sampled a middle frame from each of the 29 clip types for each of the 35 team palettes and fit it inside an 80×96 preview tile. Both light and dark background boards and a JSON record with clip/source hashes are retained here.

The first matrix review did not notice a footwear defect at contact-sheet scale. Enlarged comparison showed the broad lower-body region recolored cyan/yellow shoe accents to each target uniform palette. V6 is rejected for changing unrelated footwear pixels. V7 narrows the lower mask and preserves those source accents; its accepted evidence is recorded separately in `../attempt-07-shoe-exclusion/`.
