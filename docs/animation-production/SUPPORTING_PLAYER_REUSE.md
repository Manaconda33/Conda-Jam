# Supporting-player animation reuse

Updated 2026-10-28 for GitHub issue #7. The authorized shared-library model applies only to the 70 noncaptains. All 35 captains remain protected under the individual-art requirement and never enter the reuse map.

## Current seven-donor implementation

- Seven complete, reviewed supporting-player libraries remain original artwork: Reed Ashcroft, Juniper Vale, Piper Quickstep, Moxie Capwell, Dorian Mycel, Nova Stitch and Echo Catwalk. Their clips, frame hashes, generation provenance and mirror reviews stay in the original manifest.
- `src/content/supporting-donor-map.js` locks all 70 supporting players to those seven sources. Each source remains with its original owner and receives nine derived recipients. Supporting-player pairs on each team use different donor IDs. The map was generated by `tools/generate-supporting-donor-map.mjs` using seed `jamverse96-support-donors-issue7-v1`; runtime never reruns the assignment search.
- The seven donor masks in `src/content/supporting-uniform-profiles.js` use donor-specific hue, luma, chroma and per-clip normalized regions, with fall-specific exclusion zones where motion brings hair or skin across the uniform. `src/render/uniform-palette.js` changes RGB only within accepted garment masks, carries source shading through luminance, and leaves all alpha and out-of-mask pixels unchanged. Team colors come from `src/content/teams.js`.
- A shared player keeps their own measured ball data whenever that action/property exists. Missing values use only the assigned donor's corresponding track and scale with the recipient/donor visual-height ratio. Original library owners keep their own track lineage; missing properties remain an explicit frame-metadata fallback.
- Each atlas variant is lazy and cached per source image, donor mask and target palette. The bounded four-variant LRU avoids saving duplicate source atlases. All source images and provenance remain recoverable in `public/assets/animation/manifest.json`; variants are derived at runtime and are not labeled as newly generated artwork.

## Coverage and visual evidence

- Effective support coverage: **70 players × 29 clip types = 2,030 assignments**. Seven use their original reviewed libraries (203 clips); 63 use derived palette variants (1,827 clips). All assignments include both facings through the approved mirror policy.
- Unique source art remains seven source libraries, not 70. These libraries contain 2,053 decoded frames total (six × 293 plus Dorian's 295); derived copies do not increase authored drawings or source-atlas counts. The strict audit separately reports original, derived, unreviewed, rejected and missing classifications.
- Independent visual review covered nine target palettes per donor across all 29 clip types, using representative middle frames on light and dark boards, plus enlarged checks of the fall poses that exposed initial contamination. The latest review found no visible hair, face, skin or shoe recoloring and no broad source-uniform leaks in the reviewed cells.
- A pixel-level output check compared source and derived alpha over every frame for all 1,827 donor/palette/clip combinations: **0 alpha mismatches**. The output routine only edits RGB; transparent margins and antialiased alpha remain intact.
- Review sheets, exact target palettes, source/frame hashes, selected frame indexes, mask profile IDs and per-frame alpha/change counts are stored under `docs/animation-production/supporting-donor-palette-reviews/<donor>/`. `matrix.json` indexes each donor's light/dark 9×29 sheet and enlarged 9×7 action sheet.
- An additional real Chromium gameplay capture shows derived London and Darkspire supporters using their mapped sources and team palettes at `docs/animation-production/supporting-donor-palette-reviews/runtime/london-darkspire-chromium.png`.
- Original assets are not overwritten. Derived variants preserve donor lineage and are classified as `derived-palette`; they do not add new ImageGen provenance or inflate unique source drawing totals.

## Efficiency and runtime cost

- Compared with authoring 63 additional 29-clip libraries, this mapping reuses seven complete source libraries and avoids an estimated **1,827 bespoke clip sheets** and **18,459 source drawings** (63 × 293 as the per-player baseline). This is a production-work comparison, not a measured labor or file-size benchmark.
- Donor atlas storage is not duplicated. Derived canvases add zero persisted asset bytes. The four-entry atlas cache bounds derived RGBA memory; actual memory use depends on which donor atlases and team palettes are used during a session. No before/after browser frame-time benchmark was collected.
- Original animation timing, anchors, action selection and simulation remain unchanged. Focused tests verify all 70 players select all 29 clips in both facings and that ball-track fallback never uses an unassigned donor.

The global animation audit remains incomplete while captain gaps continue under their protected bespoke production process. Supporting reuse does not resolve or reclassify those captain gaps.
