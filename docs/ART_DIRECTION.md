# Art direction

The visual target is saturated late-arcade cabinet art: violet audience wall, warm hardwood, gold rules, teal/orange scoreboard accents, nearest-neighbor scaling, and high contrast. The internal viewport is 480×360. Floor projection uses world x/y/z, the court paints behind athletes, feet/shadows use ground coordinates, and z offsets the sprite and ball visually.

`public/assets/captain-portrait-atlas.png` is an original generated 7×5 RGBA portrait sheet, one tile per canon captain in manifest order. It is used in the title cards and 35-team selector. The generated `supporting-player-portrait-atlas.png` adds bust art for the remaining 70 athletes, used in the HUD. `team-crest-atlas.png` adds 35 original mascot crests. The 7×5 captain and 10×7 support gameplay atlases provide full-body fallback sprites for all 105 players. Supporting run atlases provide four legacy movement poses per player; two-pose action sheets cover the legacy pass, receive, push, block, rebound, pickup, celebration, shot and dunk states. Every grid uses manifest order, transparent backgrounds and runtime cell dimensions. Sprites scale by stature and court depth, mirror for direction, bob with motion, rise with simulation z, and retain knockdown, ball, marker and name overlays. The current production manifest adds 270 reviewed animation atlases with 2,341 distinct authored drawings for 43 athletes. The standalone build embeds these animation atlases plus the roster and legacy action art; the static build copies them to `dist/public/assets/`.

The production manifest currently covers 43 athletes with reviewed per-state clips; the remaining 62 athletes still rely on the earlier shared pose sets. Canonical nonhuman rigs have dedicated anatomy branches for the kit fox (four-footed, pointed ears, muzzle/tail), dragon (wings, four limbs, gold flecks, ceremonial cloth and long tail), cobra (expanded hood, markings, face mask and coils), wombat (barrel body, short legs and lantern), jaguar (feline muzzle, spots and flag jersey), zebra-orangutan hybrid (striped orange body with extra-long arms and hands), and android (noir torso and a blank screen beneath a fedora). Humans and fantasy humanoids use character-specific hair, glasses, horns, ears, wings, hat, antlers, or other feature tags where implemented. The 29-clip-per-athlete production set remains incomplete: the strict audit reports 1,035 missing clips, 62 unrepresented athletes and three clips below their target frame counts (Dorian Mycel dribble and dribble-run; Luca Velori run). The generated legacy action sheets still provide only two poses per action.

The gameplay sprite art is original, generated for this project and composed into the game without external requests. Reviewed production clips are selected from the live simulation action and tick; unsupported clips still use the shared generated action sheets or procedural fallbacks. Stature-based scaling and canonical animal silhouettes remain. Visual review exposed and corrected the Wombat rig's missing full body, improved long-arm zebra framing, strengthened Dragon Queen/Suga anatomy cues, and added a noir body/fedora to Alexithymia. All 35 captains have reviewed locomotion art, but most lack their full action set; 62 supporting athletes do not yet have registered production clips. Screenshots in `artifacts/screenshots/` are actual browser captures, not mockups.
