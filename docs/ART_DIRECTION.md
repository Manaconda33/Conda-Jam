# Art direction

The visual target is saturated late-arcade cabinet art: violet audience wall, warm hardwood, gold rules, teal/orange scoreboard accents, nearest-neighbor scaling, and high contrast. The internal viewport is 480×360. Floor projection uses world x/y/z, the court paints behind athletes, feet/shadows use ground coordinates, and z offsets the sprite and ball visually.

`public/assets/captain-portrait-atlas.png` is an original generated 7×5 RGBA portrait sheet, one tile per canon captain in manifest order. It is used in the title cards and 35-team selector. The generated `supporting-player-portrait-atlas.png` adds bust art for the remaining 70 athletes, used in the HUD. `team-crest-atlas.png` adds 35 original mascot crests. The 7×5 captain and 10×7 support gameplay atlases provide all 105 full-body player sprites. Matching run-pose atlases add a second generated pose for every player; while running, the renderer switches between base and run poses every 145 ms. Jump-shot and dunk atlases provide dedicated poses during those actions. Every grid uses manifest order, transparent backgrounds, and runtime cell dimensions. Sprites scale by stature and court depth, mirror for direction, bob with motion, rise with simulation z, and retain knockdown, ball, marker, and name overlays. The standalone build embeds all eleven generated PNG atlases; the static build copies them to `dist/public/assets/`.

Each player has generated portrait art and four full-body poses, with a two-pose run cycle and dedicated jump-shot and dunk poses. Canonical nonhuman rigs have dedicated anatomy branches for the kit fox (four-footed, pointed ears, muzzle/tail), dragon (wings, four limbs, gold flecks, ceremonial cloth and long tail), cobra (expanded hood, markings, face mask and coils), wombat (barrel body, short legs and lantern), jaguar (feline muzzle, spots and flag jersey), zebra-orangutan hybrid (striped orange body with extra-long arms and hands), and android (noir torso and a blank screen beneath a fedora). Humans and fantasy humanoids use character-specific hair, glasses, horns, ears, wings, hat, antlers, or other feature tags where implemented. The requested full idle, eight-direction run, dribble, turbo, pass, multi-frame jumper and dunk, defense, block, steal, shove, recoil, knockdown, get-up, rebound, fire, and bench frame sets are still incomplete; the generated action sheets are one pose per action rather than hand-authored frame sequences.

The gameplay sprite art is original, generated for this project and composed into the game without external requests. The existing procedural rigs remain as a loading fallback and for action-specific procedural effects. Humanoid athletes have drawn limbs, running gait, block/shoot/dunk arm poses, a brief directional pass pose, and a timed raised-arm scoring celebration; the zebra-orangutan's long arms exaggerate the celebration. Stature-based scaling and canonical animal silhouettes remain. Visual review exposed and corrected the Wombat rig's missing full body, improved long-arm zebra framing, strengthened Dragon Queen/Suga anatomy cues, and added a noir body/fedora to Alexithymia. The generated atlases do not yet meet the requested per-state frame counts, eight-direction run sheets, or full signature animation set. Screenshots in `artifacts/screenshots/` are actual browser captures, not mockups.
