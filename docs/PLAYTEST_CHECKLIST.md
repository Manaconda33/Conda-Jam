# Playtest checklist

- [ ] Play a normal 3:00-per-quarter match from menu to final buzzer using WASD.
- [ ] Test pass to the partner, steal attempt, missed-shot rebound, open 2, open 3, contested shot and close dunk.
- [ ] Verify both directions, near/far depth, camera, hoop readability and left/right scoring arc.
- [ ] Test Paprika, Dragon Queen, Suga, Steeb, GB Design, Kraken, Quirky, Alexithymia and E. Indigo in both roster art and court play.
- [ ] Test fire streak trigger and cool-off; confirm it does not obscure the ball.
- [ ] Test player substitutions, both keyboard layouts, two gamepads, disconnect, focus loss and rematch.
- [ ] Test season advancement, save reload, storage denial, screen resize, settings labels and reduced flash.
- [ ] Review screenshot evidence at 720p and 1080p. Record stutter and input delay.
