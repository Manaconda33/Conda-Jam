# Captain portrait atlas recipe

## Output

- File: `public/assets/captain-portrait-atlas.png`
- Format: RGBA PNG with transparent background
- Grid: 7 columns × 5 rows, no dividers, equal 212 × 212 pixel tiles
- One original head-and-shoulders portrait per tile
- Tile order: same as `src/content/teams.js`, row-major
- Runtime use: the team index chooses the tile in `drawCaptainCard`; the standalone build embeds this PNG as a data URI

Equal square cells, no visible grid, no borders, transparent padding around every character, consistent head scale and three-quarter forward pose, clean 1990s pixel clusters, bright readable limited palettes, no text or logos. ## Validation

`tests/portrait-atlas.test.js` verifies PNG format, RGBA transparency, exact grid dimensions and inclusion. `tools/e2e_smoke.py` checks that all 35 team cards render portraits from the atlas. `npm run build` embeds it into `dist/JAMVERSE_96.html`; the standalone browser journey verifies it makes no external requests.
